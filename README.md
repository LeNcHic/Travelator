# Travelator

Веб-приложение для персональных маршрутов по Китаю на React, TypeScript и Vite. Выберите срок, интересы и темп поездки, сравните до трёх маршрутов и откройте план по дням. В каталоге 40 баз проживания и 207 мест.

## Быстрый запуск

Понадобятся **Node.js 22.12 или новее**, npm и Git. npm устанавливается вместе с Node.js. Проверить версии можно командами `node --version` и `npm --version`. Для установки зависимостей и обращения к внешним источникам нужен интернет.

Откройте терминал и выполните:

```sh
git clone https://github.com/LeNcHic/Travelator.git
cd Travelator
npm ci
npm run dev
```

Если репозиторий уже скачан, откройте его папку в терминале и начните с `npm ci`.

Откройте **[http://127.0.0.1:5173/](http://127.0.0.1:5173/)**. Терминал должен оставаться открытым. Если порт занят, Vite напечатает другой адрес. Чтобы остановить сервер, нажмите **Ctrl+C** в терминале.

**Для первого запуска токен не обязателен:** форма, предварительный подбор, план по дням и сохранение поездок работают на локальном каталоге. Для онлайн-проверки гостиниц, авиабилетов и пересчёта маршрутов по предложениям нужен токен FlyAI.

## Токен FlyAI

Используйте действующий токен FlyAI. Приложение читает его на сервере из переменной `FLYAI_API_KEY`.

1. В корне проекта, рядом с `package.json`, создайте `.env.local` из шаблона:

   ```sh
   cp .env.example .env.local
   ```

   В PowerShell: `Copy-Item .env.example .env.local`. Если `.env.local` уже существует, отредактируйте его, сохранив текущие настройки.

2. Откройте `.env.local` в редакторе и вставьте свой токен вместо примера:

   ```dotenv
   FLYAI_API_KEY=YOUR_FLYAI_API_KEY
   ```

   `YOUR_FLYAI_API_KEY` здесь обозначает место для вашего токена. В файле должна быть его фактическая строка.

3. Остановите сервер через **Ctrl+C** и запустите заново:

   ```sh
   npm run dev
   ```

Отдельно устанавливать FlyAI CLI или запускать MCP-сервер не нужно: пакет `@fly-ai/flyai-cli` входит в зависимости, сервер приложения вызывает его сам.

| Функция | Нужен токен FlyAI |
|---|---|
| Предварительные маршруты, план по дням, редактирование и сохранения | Нет |
| Погода Open-Meteo и официальная афиша | Нет, нужен интернет |
| Расписания RailGo | Нет, нужен интернет |
| Гостиницы и авиабилеты Fliggy, онлайн-пересчёт маршрутов | Да, также нужен интернет |

В репозитории хранится только **[.env.example](.env.example)** с пустым значением. `.env.local` исключён из Git. Не добавляйте токен в README и не используйте для него префикс `VITE_`: такие переменные доступны клиентскому коду. На другом компьютере создайте `.env.local` заново. При настройке сервера задайте `FLYAI_API_KEY` в его окружении или хранилище секретов.

## Как проверить запуск

1. Откройте приложение и задайте срок, интересы и темп поездки.
2. Перейдите к вариантам, выберите маршрут и откройте план по дням.
3. Для онлайн-проверки укажите точные будущие даты, настройте токен и в разделе **«Цены и актуальные предложения»** нажмите **«Уточнить предложения»**.
4. Сохраните поездку и обновите страницу: сохранение останется в том же браузере по тому же адресу.

Отсутствие ответа внешнего источника не мешает открыть предварительный план. Погода и афиша могут обновляться отдельно от предложений гостиниц и транспорта.

## Презентация

Готовая презентация находится в **[presentation.html](presentation.html)**. Это самостоятельный HTML-файл со встроенными изображениями, его можно скачать и открыть в браузере без запуска приложения.

При работающем `npm run dev` она также доступна по адресу **[http://127.0.0.1:5173/presentation.html](http://127.0.0.1:5173/presentation.html)**. Если Vite выбрал другой порт, замените его в адресе.

Управление: **← / →** листают слайды, **O** открывает список слайдов, **N** показывает заметки докладчика, **F** включает полный экран. **Ctrl+P / ⌘+P** открывает печать в PDF.

На GitHub HTML отображается как исходный код. Для просмотра слайдов откройте скачанный файл или адрес локального сервера. Презентация хранится в корне проекта и не включается автоматически в сборку `dist/`.

## Команды

Все команды выполняйте из корня проекта.

| Команда | Что делает |
|---|---|
| `npm ci` | Устанавливает версии зависимостей из `package-lock.json` |
| `npm run dev` | Запускает приложение и серверные API, обычно на порту 5173 |
| `npm test` | Проверяет алгоритм, API и восстановление поездок |
| `npm run build` | Проверяет TypeScript и создаёт сборку в `dist/` |
| `npm run preview` | Запускает локальный просмотр готовой сборки вместе с API, обычно на порту 4173 |

Чтобы проверить сборку:

```sh
npm run build
npm run preview
```

Откройте **[http://127.0.0.1:4173/](http://127.0.0.1:4173/)** или адрес из терминала.

Серверные API подключены в `vite.config.ts` и работают при `dev` и `preview`. Открытие `index.html` через `file://`, GitHub Pages или простая раздача папки `dist/` не запускают эти API. Для публикации полного приложения нужен Node.js-сервер с серверными адаптерами. `vite preview` предназначен для локальной проверки; отдельный production-сервер в проекте пока не подготовлен.

## Частые проблемы

| Симптом | Что проверить |
|---|---|
| Терминал не находит `node` или `npm` | Установите Node.js 22.12+ с npm и заново откройте терминал |
| `npm ci` не устанавливает зависимости | Проверьте интернет и версию Node.js, запускайте команду рядом с `package.json` и `package-lock.json` |
| Адрес на порту 5173 не открывается | Убедитесь, что `npm run dev` работает, используйте адрес из терминала. Другой порт: `npm run dev -- --port 5174` |
| Сообщение о личном ключе или `PERSONAL_KEY_REQUIRED` | Проверьте `FLYAI_API_KEY` в `.env.local` в корне проекта и перезапустите сервер |
| FlyAI возвращает 429 или ограничение доступа 451 | Это ограничение поставщика. Повторите позже; предварительный план остаётся доступен |
| Погода, афиша или предложения не загружаются | Запускайте приложение через `npm run dev` или `npm run preview`, проверьте интернет. Доступность источников может меняться |
| Вместо полной цены видны скрытые цифры | Поставщик не подтвердил полную стоимость. Уточните доступ токена и итоговый тариф у поставщика |
| Не видно сохранённой поездки | Используйте тот же браузер, профиль и адрес, включая порт. Сохранения находятся в localStorage и удаляются при очистке данных сайта |

## Возможности

- Одна короткая форма: 5–28 дней, города/природа/море и темп. Бюджет, транспорт и обязательные места — дополнительные пожелания.
- Подбор порядка городов и распределение дней с учётом программы, длительности посещений, свободного времени и убывающей пользы повторных занятий. Весь срок отдан остановкам; межгородская дорога показана отдельно.
- До трёх разных наборов мест с ценой, длительностью переездов и объяснением преимуществ. Перестановки тех же городов не создают искусственных альтернатив.
- Настройки «Меньше переездов», «Больше природы», «Закончить у моря» с результатом, объяснением недоступности и отменой.
- Подробный план: города, дни, переезды, гостиницы, карта и перенос посещений между днями.
- Погода и афиша уточняются после предварительного подбора. Пересчёт рекомендаций применяется явно, выбранный план и ручные изменения сохраняются.
- Черновик и сохранённые поездки хранятся в localStorage текущего браузера; очистка данных сайта их удалит. Авторизации и облачной синхронизации нет.

Подбор, быстрые изменения и поиск поправок при несовместимых пожеланиях выполняются в Web Worker, чтобы не блокировать календарь и кнопки. Возврат к форме или смена пожеланий прекращают предыдущий расчёт. В памяти вкладки хранится до 24 результатов на одну минуту; ошибка или таймаут 30 секунд дают возможность повторить расчёт. Внешние предложения проверяются отдельно.

## Внешние данные

| Источник | Использование | Ограничения |
|---|---|---|
| Open-Meteo | Прогноз на ближайшие 16 календарных дней; далее сезонный ориентир по архиву трёх полных лет | Покрытие, тип данных и время обновления видны в плане; сезонный ориентир не заменяет прогноз |
| Официальные порталы и организаторы | События на даты остановок, совпадающие с интересами | Выборочная афиша; регистрация и наличие билетов могут быть неизвестны |
| RailGo | Расписания поездов до двух часов | Тарифы и наличие мест неизвестны; цена поезда остаётся ориентировочной |
| FlyAI / Fliggy | Поисковые цены гостиниц за ночь и прямых внутренних рейсов | Нужен токен; возможны дополнительные сборы и ограничения поставщика |

Примеры источников афиши: [портал Шанхая](https://english.shanghai.gov.cn/en-Events/), [портал Пекина](https://english.beijing.gov.cn/whatson/), сайты музеев и организаторов. Список источников и часть карточек событий заданы в коде, сервер перепроверяет даты по страницам. Это выборка событий, а не полная афиша всех городов.

Названия гостиниц сохраняются в оригинале, интерфейс работает на русском. Островок представлен заготовкой адаптера; поиск через него не подключён. Расчёт стоимости включает проживание и переезды внутри Китая для одного человека. Международные билеты, питание и экскурсии в него не входят. Поисковые цены не подтверждают бронирование, наличие мест или итоговые сборы.

Бесплатные endpoint Open-Meteo используются для некоммерческого проекта: перед коммерческой публикацией проверьте [условия использования](https://open-meteo.com/en/terms) и лимиты всех поставщиков.

## Устройство проекта

- `src/` — интерфейс, локальный каталог, алгоритм маршрутов, редактирование и сохранения.
- `src/lib/algorithm-settings.ts` — веса и ограничения подбора.
- `shared/` — общие контракты API и справочники направлений, станций и аэропортов.
- `server/` — адаптеры источников с проверкой данных, кешированием, таймаутами и ограничениями запросов.
- `public/` — необходимые изображения, иллюстрация новых направлений и сведения об авторстве.

Данные баз содержат страну, регион, часовой пояс, выезды и источники. Неполные записи не участвуют в подборе. Для добавления страны нужны её каталог, связи, валюта и региональные адаптеры предложений; сейчас реализованы Китай и CNY.

Координаты мест, длительности, редакционные оценки интересов, предварительные гостиницы и транспортные связи в локальном каталоге — ориентировочные данные. Они не подтверждают часы работы, действующее прямое сообщение или доступность билетов. Алгоритм использует ограниченный графовый поиск и не гарантирует глобальный оптимум.
