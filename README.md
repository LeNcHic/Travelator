# Travelator

Учебное веб-приложение для составления персональных маршрутов на React, TypeScript и Vite. Пользователь выбирает срок, интересы и темп, приложение предлагает до трёх разных маршрутов и распределяет дни. Китай — первое доступное направление: 40 баз проживания и 207 мест.

## Запуск

Нужен Node.js 22.12 или новее и npm.

```sh
npm ci
npm run dev
```

Приложение доступно по адресу http://127.0.0.1:5173/ (если порт занят, Vite покажет другой адрес).

```sh
npm test          # Проверки алгоритма, API и восстановления поездок
npm run build    # Проверка TypeScript и сборка
npm run preview  # Просмотр сборки с серверными адаптерами
```

Серверные API подключены в `vite.config.ts` и работают при `dev` и `preview`. Открытие `index.html` через `file://` или раздача одной папки `dist/` не запускает поиск погоды, афиши и предложений. Vite preview предназначен для локальной проверки; отдельный production-сервер пока не подготовлен.

## Возможности

- Одна короткая форма: 5–28 дней, города/природа/море и темп. Бюджет, транспорт и обязательные места — дополнительные пожелания.
- Подбор порядка городов и распределение дней с учётом программы, длительности посещений, свободного времени и убывающей пользы повторных занятий. Весь срок отдан остановкам; межгородская дорога показана отдельно.
- До трёх разных наборов мест с ценой, длительностью переездов и объяснением преимуществ. Перестановки тех же городов не создают искусственных альтернатив.
- Настройки «Меньше переездов», «Больше природы», «Закончить у моря» с результатом, объяснением недоступности и отменой.
- Подробный план: города, дни, переезды, гостиницы, карта и перенос посещений между днями.
- Погода и афиша уточняются после предварительного подбора. Пересчёт рекомендаций применяется явно, выбранный план и ручные изменения сохраняются.
- Черновик и сохранённые поездки хранятся в localStorage текущего браузера; очистка данных сайта их удалит. Авторизации и облачной синхронизации нет.

Подбор, быстрые изменения и поиск поправок при несовместимых пожеланиях выполняются в Web Worker, чтобы не блокировать календарь и кнопки. Возврат к форме или смена пожеланий прекращают предыдущий расчёт. В памяти вкладки хранится до 24 результатов на одну минуту; ошибка или таймаут 30 секунд дают возможность повторить расчёт. Внешние предложения проверяются отдельно.

## Внешние данные и ключ

Предварительный план работает без ключей. Для внешних источников серверу нужен интернет.

| Источник | Использование | Ограничения |
|---|---|---|
| Open-Meteo | Прогноз на ближайшие 16 календарных дней; далее сезонный ориентир по архиву трёх полных лет | Не прогноз на далёкую дату и не оценка безопасности пляжа; покрытие, тип данных и время обновления видны в плане |
| Официальные порталы и организаторы | События на даты остановок, совпадающие с интересами | Выборочная афиша; регистрация и наличие билетов могут быть неизвестны |
| RailGo | Расписания поездов до двух часов | Тарифы и наличие мест неизвестны; цена поезда остаётся учебной оценкой |
| FlyAI / Fliggy | Поисковые цены гостиниц за ночь и прямых внутренних рейсов | Не бронирование; возможны дополнительные сборы, лимиты и risk control поставщика |

Для FlyAI создайте локальный файл настроек:

```sh
cp .env.example .env.local
```

Заполните `FLYAI_API_KEY` в `.env.local`, затем перезапустите сервер. Ключ читается только сервером. Не используйте префикс `VITE_` для секретов. `.env.local` не хранится в Git; реальные ключи в репозитории не нужны.

При ошибках внешних источников предварительные маршруты остаются доступны. FlyAI HTTP 451/429 останавливает обращения без обхода ограничений. Названия гостиниц сохраняются в оригинале, интерфейс — на русском. Островок пока представлен заготовкой адаптера; поиск через него не подключён.

Бесплатные endpoint Open-Meteo используются для некоммерческого учебного проекта: перед коммерческой публикацией проверьте [условия использования](https://open-meteo.com/en/terms) и лимиты всех поставщиков.

## Устройство проекта

- `src/` — интерфейс, локальный каталог, алгоритм маршрутов, редактирование и сохранения.
- `src/lib/algorithm-settings.ts` — веса и ограничения подбора.
- `shared/` — общие контракты API и справочники направлений, станций и аэропортов.
- `server/` — адаптеры источников с проверкой данных, кешированием, таймаутами и ограничениями запросов.
- `public/` — необходимые изображения, иллюстрация новых направлений и сведения об авторстве.

Данные баз содержат страну, регион, часовой пояс, выезды и источники. Неполные записи не участвуют в подборе. Для добавления страны нужны её каталог, связи, валюта и региональные адаптеры предложений; сейчас реализованы Китай и CNY.

Координаты мест, длительности, редакционные оценки интересов, предварительные гостиницы и транспортные связи — учебные данные. Они не подтверждают часы работы, действующее прямое сообщение или доступность билетов. Алгоритм использует ограниченный графовый поиск и не гарантирует глобальный оптимум.
